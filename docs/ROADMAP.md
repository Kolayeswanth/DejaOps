# Roadmap

## Current

- Streamlit alert triage with generic and memory-assisted comparison.
- Hindsight retention, recall, reflection, and graph listing.
- Incident and runbook seed data for Northwind Payments.
- Worked/Failed feedback and memory-aware recommendation rules.
- Evidence, warning, rejection, provenance, and memory graph visualization.

## Next

- Live alert source adapters.
- Broader observability context and incident tooling.
- More explicit evaluation cases for retrieval, provenance, and recommendation behavior.
- Additional outcome classifications and correction workflows for operational memory.
- Runtime telemetry for recall, model, retention, and end-to-end triage stages.

## Future

- Automated remediation with approval and audit boundaries.
- Multi-agent investigation and specialized domain adapters.
- Organization-specific memory policies and larger operational datasets.
- Production integrations for alerting, observability, collaboration, and deployment systems.
